# «Мой день» — Версия для macOS

Отдельная версия настольного приложения для macOS в спокойной эстетике Apple Liquid Glass с поддержкой школьного расписания уроков, синхронизацией звонков, трекером сна и планированием задач.

---

## Что адаптировано под macOS

1. **Системные шрифты Apple**:
   - Автоматическое использование **San Francisco (SF Pro, SF Pro Display / Text)**, **Helvetica Neue** и **Menlo / Monaco** для моноширинных блоков с плавным системным фоллбэком.
2. **Нативные сочетания клавиш (⌘ Command)**:
   - `⌘1` — «Сегодня»
   - `⌘2` — «Уроки»
   - `⌘3` — «Расписание»
   - `⌘4` — «Задачи»
   - `⌘5` — «Оценки»
   - `⌘6` — «Сон»
   - `⌘7` — «Настройки»
   - `⌘D` — переключение тёмной и светлой темы
   - `⌘Z` — отмена последнего действия (Undo)
3. **Хранилище данных по стандартам macOS**:
   - `~/Library/Application Support/StudyPlanner/planner.json`
   - Локальный JSON-файл, изолированный от облаков, без скрытой телеметрии.
   - Кнопка «Открыть папку данных» в «Настройках» вызывает системный `open` в Finder.
4. **Формат macOS Application Bundle (`.app`)**:
   - Скрипт сборки автоматически упаковывает исполняемый файл в `dist/Мой день.app` с манифестом `Info.plist`, поддержкой Retina-экранов (`NSHighResolutionCapable`) и тёмной темы.

## Быстрый запуск на Mac

### 1. Требования
- macOS 11.0 (Big Sur) или новее (поддерживаются как Apple Silicon M1/M2/M3/M4, так и Intel x86_64).
- Установленный Rust (если ещё не установлен, одна команда в Терминале):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```

### 2. Сборка и запуск одной командой
Откройте Терминал в этой папке и выполните:
```bash
chmod +x build.sh run.sh
./run.sh
```

- `./build.sh` — прогонит автоматические тесты, скомпилирует оптимизированную релизную сборку и создаст готовый бандл `dist/Мой день.app`.
- `./run.sh` — запустит `dist/Мой день.app` (или предварительно соберёт его, если бандл ещё не создан).
- Также можно дважды кликнуть на `dist/Мой день.app` прямо в Finder.

## Структура папки

```text
Версия для Mac/
├── bundle/
│   └── Info.plist          # Манифест приложения для macOS (название, идентификатор, Retina)
├── src/                    # Исходный код на Rust с адаптацией под macOS
│   ├── ui/                 # Экраны (Сегодня, Уроки, Расписание, Задачи, Оценки, Сон, Настройки)
│   ├── glass.rs            # Liquid Glass и визуальные материалы
│   ├── model.rs            # Модели данных, уроки, звонки, сон, откат
│   └── motion.rs           # Пружинная анимация Apple Spring Motion
├── build.sh                # Скрипт сборки macOS App Bundle
├── run.sh                  # Скрипт запуска на macOS
├── Cargo.toml              # Конфигурация зависимостей Rust
└── README.md               # Данная инструкция
```
