# Мой день — первая рабочая версия

Нативное Windows-приложение на Rust (eframe/egui). Запуск: `dist/Мой день.exe`.

## Что работает
- Расписание на неделю. Уроки, секции, места и дорога. Разовые даты и исключения из серии.
- Задачи: предмет, срок, оценка времени, выполнение, редактирование и удаление.
- Оценки: предмет, дата, комментарий, настраиваемый максимум шкалы, среднее.
- План следующего вечера по первому занятию завтра: дорога, запас, сборы, сон и засыпание. Времена показаны с датами.
- Дневник сна: ручной ввод всех согласованных показателей и сновидений. Длительность сна на графике, среднее по имеющимся записям. Пустые измерения не превращаются в нули.
- Светлая/тёмная тема. Отдельное перемещаемое окно виджета. Опциональное закрепление поверх окон.
- Значок в трее. Закрытие основного окна оставляет приложение работать; открыть или завершить его можно через меню значка.
- Автосохранение локального JSON с резервной копией предыдущей версии. Отмена последнего сохранённого изменения списка и ручная резервная копия.

## Ограничения этой версии
Виджет является отдельным окном Windows, ещё не прикреплён к слою рабочего стола Explorer. Автозапуск, системные напоминания, автоматическая раскладка задач по свободным интервалам, недельная календарная сетка и расширенные графики пульса/фаз сна — следующие этапы. Сейчас эти показатели сохраняются в дневнике. Визуальная система реализована в первом приближении; эффект Liquid Glass не добавлен.

Даты вводятся как ГГГГ-ММ-ДД, время как ЧЧ:ММ. Десятичные значения вводятся через точку. Для изменения одного урока добавь его дату в исключения серии и создай разовое занятие на эту дату. Сон записывается по дате пробуждения.

## Данные
Путь виден в настройках (Local AppData, StudyPlanner). `planner.backup.json` — предыдущее сохранение. При ошибке чтения приложение не перезаписывает исходный файл. Для восстановления закрой приложение через трей, сохрани копию повреждённого файла и восстанови `planner.json` из резервной копии.

## Сборка
`powershell -ExecutionPolicy Bypass -File build.ps1`

На этом компьютере установлены Rust GNU и локальный w64devkit в `tools`. Для совместимости Rust с объединённой библиотекой GCC создана копия `libgcc.a` под именем `libgcc_eh.a`. Список точных версий зависимостей зафиксирован в Cargo.lock. Готовому приложению компилятор не нужен.
