# Мой день — версия с дизайном Apple Liquid Glass и моушеном

> Создано через Gemini в отдельной папке `Сделано через Джемини`. Исходный проект в корневой папке `StudyPlanner` сохранён без изменений как резервная копия.

## Что нового в этом дизайне
* **Apple Liquid Glass (macOS-эстетика на Windows 11):**
  * нативная поддержка **Windows 11 DWM Mica** для основного окна, **Acrylic** для виджета рабочего стола, скругления углов и тёмной/светлой рамки окна;
  * парящая стеклянная боковая панель (вкладыш `16 px` с концентрической активной капсулой `10 px`), блики верхних граней (specular highlights), тонкие двойные контуры и чистый непрозрачно-устойчивый слой контента;
  * единая система векторных монохромных иконок (вместо текстовых кружков и эмодзи) и реальная весовая иерархия шрифтов (`Segoe UI` Regular + Semibold + Bold).
* **Пружинная физика движения (Motion):**
  * плавное скольжение активной капсулы в боковом меню и сегментированных переключателях;
  * тактильные круглые чекбоксы в стиле **Apple Reminders** с анимированной галочкой и тёплым акцентом;
  * мягкий переход между экранами и всплывающая стеклянная HUD-панель с отменой действия (`Ctrl+Z`);
  * автоматический учёт системной настройки Windows **«Уменьшить движение»** и отдельные переключатели прозрачности и анимаций в «Настройках».
* **Продуктовые улучшения:**
  * **Сегодня:** быстрое добавление задач прямо на экране дня, проверка вместимости текущих задач в *реальные свободные окна* до времени завершения дел (с учётом дороги и буфера), приглашение на еженедельную сверку уроков в начале недели, кнопка загрузки/очистки демонстрационной недели;
  * **Уроки:** отдельный раздел школьного расписания с выбором предметов галочками без ручного переписывания, упорядочиванием последовательности (`↑`/`↓`), настройкой времени начала уроков, возвращения домой, длительности урока/перемены и автоматическим обновлением сетки «Расписания» и доступных дневных окон;
  * **Расписание:** полноценная **недельная календарная сетка** с выделением сегодняшнего дня, тонкой линией текущего времени, цвето-текстовыми категориями («Учёба», «Секция», «Личное», «Контрольная») и правкой в один клик **«Только эту дату» / «Всю серию»**;
  * **Задачи:** разделение на активные и свёрнутую группу «Выполненные», обратимость переключения чекбоксов через `undo`;
  * **Сон:** переключение «План и обзор» / «Дневник», 6-шаговая шкала вечернего плана и отдельные сводки фаз/пульса/дыхания (пропуски остаются пропусками);
  * **Виджет рабочего стола:** безрамочная перетаскиваемая стеклянная карточка на рабочем столе с синхронизацией задач, кнопкой закрепления поверх окон и быстрым открытием основного окна.

## Горячие клавиши
* `Ctrl + 1..7` — переключение разделов («Сегодня» … «Настройки»)
* `Ctrl + D` — светлая / тёмная тема
* `Ctrl + Z` — отмена последнего изменения

## Сборка и запуск
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
Собранное приложение: `dist\Мой день.exe`.
Данные сохраняются локально в `%LOCALAPPDATA%\StudyPlanner\planner.json` (совместимы с форматом резервной версии).
